<headers>
Check first:
- "No such file" → Check case-sensitive paths
- "internal/*" paths → Remove, use public API only
- C API conflicts → Keep *_c.h, remove *.h
- "typedef redefinition" → Header conflict, keep only one
</headers>

<linker_errors>
- "undefined reference" → Add #include "impl.cpp" (not forward declare)
- Check existing fuzzers: grep '#include.*\.cpp' for pattern
- If no .cpp pattern exists → Report UNABLE_TO_FIX
</linker_errors>

<api_call_errors>
- Type mismatch → Fix signatures/casts
- Const violations → Add/remove const qualifiers
- Wrong parameters → Check API documentation
</api_call_errors>

<types_api>
- Deprecated APIs → Update to current API
- Uninitialized variables → Initialize before use
- Missing includes → Add required headers
</types_api>

</error_patterns>
