Output JSON:
{{
    "is_structured": true,
    "format_type": "tlv|fixed_header|length_prefixed|raw|unknown",
    "min_size": 4,
    "magic_bytes": "0x89504E47",
    "constraints": ["length at offset 4"],
    "reasoning": "..."
}}

Format types:
- tlv: Type-Length-Value encoding
- fixed_header: fixed-size header + payload
- length_prefixed: length field + data
- raw: unstructured bytes

Set magic_bytes to null if none required.
